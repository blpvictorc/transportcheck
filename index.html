翔東邨及周邊巴士站位懶人包

邊架車喺樓下總站搭？邊架車要行去迎東邨/昇薈？

📍 1. 翔東邨巴士總站 / 翔月樓 (樓下直達) 步行 1-2 分鐘

位於翔東邨內及裕東路翔月樓外，落樓即達，唔使日曬雨淋行遠路：

  • 嶼巴 37A：翔東邨 ↺ 東涌站巴士總站（全日主力駁腳去東涌地鐵站/東薈城，約 6-12 分鐘一班）
  • 嶼巴 36M：翔東邨 → 欣澳站（平日早上繁忙時間特快駁東涌綫，避開東涌市中心塞車）
  • 城巴 E18：翔東邨 ↔ 北角碼頭（直達西隧、上環、中環、金鐘、灣仔、銅鑼灣、天后、北角）
  • 城巴 E28：翔東邨 ↔ 將軍澳工業邨（直達黃大仙、鑽石山、彩虹、九龍灣、觀塘、將軍澳、調景嶺、康城）
  • 龍運 S64P：經翔東邨 / 翔月樓 往返機場航膳區、貨運區及東涌站
🚶 2. 迎東邨巴士總站 / 迎東邨站 (鄰近屋邨) 步行約 5-7 分鐘

沿迎東路向西行去迎東邨商場旁巴士總站，有大量跨區 E 線同埋 37M：

  • 城巴 E21A / E21D：直達深水埗、旺角（朗豪坊/彌敦道）、油麻地、何文田愛民邨；E21X 早繁直達紅磡站
  • 城巴 E11A / E11B：往返中上環、金鐘、灣仔、銅鑼灣、天后（可同 E18 互補班次）
  • 龍運 E32A / E36A：E32A 直達荃灣、葵芳、葵興；E36A 繁忙時間直達屯門、元朗
  • 嶼巴 37M / 37 / 37H：37M 密車去東涌站；37/37H 去北大嶼山醫院、映灣園、逸東邨、滿東邨
🚶 3. 昇薈 / 迎禧路 (迎禧路沿線巴士站) 步行約 7-9 分鐘

部分特別班次及通宵車途經迎禧路（昇薈外）：

  • 龍運 E42P：平日早繁直達大圍、沙田市中心、火炭
  • 城巴 E22S：平日繁時往返黃大仙、九龍灣、觀塘、將軍澳寶琳
  • 城巴 S52A / S56：往返機場客運大樓 (T1) 及飛機維修區
  • 龍運 N31 / 城巴 N11 / N21A：深宵通宵往返機場、荃葵青、旺角及港島

翔東街坊必學：青馬／屯赤轉車站慳錢慳時秘笈

善用八達通/電子支付轉乘優惠，去全港各區更快更平！

💡 秘技 1：青嶼幹線轉車站（青馬收費廣場）萬能轉車

喺翔東邨搭 E18 / E28（或者迎東邨搭 E21A / E21D / E11A / E32A），出九龍/新界方向喺「青嶼幹線轉車站」落車，同站即刻轉乘其他路線，享有八達通轉乘減免：

去沙田 / 大圍
轉乘 龍運 E42 / A41（第二程只須補差價約 $3.1）
去大埔 / 太和
轉乘 龍運 E41 / A47X（直達大埔中心、廣福邨）
去粉嶺 / 上水
轉乘 龍運 A43 / A43P（特快直達上水站、粉嶺）
去馬鞍山 / 烏溪沙
轉乘 龍運 A41P / A42（直達顯徑、第一城、馬鞍山）
去港島南區 (香港仔/鴨脷洲)
轉乘 城巴 A10 或喺西隧轉 970/970X/973
返翔東邨萬能搭法
喺青馬轉車站見 E18 / E28 即上直返翔東樓下！

🚇 秘技 2：屯門赤鱲角隧道轉車站（去屯門・元朗・天水圍最快）

除咗平日早晚繁時喺迎東邨搭 E36A 直達之外，其餘時間可以搭 37A 去東涌站 / 順東路，或者去迎東搭車去「屯門赤鱲角隧道轉車站」轉乘：

  • 去屯門市中心/兆康：轉乘 E33 / E33P / A33X（經屯赤隧道 15 分鐘即到屯門）
  • 去元朗 / 形點 YOHO：轉乘 E36 / A36
  • 去天水圍 / 濕地公園：轉乘 E37 / A37

九巴 KMB / 龍運 LWB 全港實時到站查車

直連九巴官方開放數據 (`data.etabus.gov.hk`)，支援查詢全港超過 400 條九巴及龍運轉乘線！

💡 翔東街坊搭九巴小貼士：

東涌往返新界各區嘅 龍運巴士 (LWB：S64P、E32A、E36A、E31、E33、E36、E37、E41、E42) 與 九巴 (KMB) 屬於同一集團，喺青嶼幹線轉車站、屯赤隧道轉車站、美孚、荃灣、沙田或黃大仙轉乘任何九巴路線（如 258D、259D、290X、74X、101、1A 等）均享有八達通轉乘優惠！

常用九巴/龍運轉乘線：
請喺上方輸入或揀選任何九巴 (KMB) / 龍運 (LWB) 路線編號，即可查閱雙向分站及實時到站倒數。
